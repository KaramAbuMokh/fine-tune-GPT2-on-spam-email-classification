# fine-tune-GPT2-on-spam-email-classification

Purpose: the notebook that re-wires a hand-written GPT-2 small into a text-message spam classifier and fine-tunes it. A public repository of Karam Abu Mokh, shown on his portfolio (karamam.com).

## Files
- `README.md`: what the project is, the data split, the accuracy numbers and how they were measured, how to run it and the structure.
- `fine_tuning.ipynb`: the whole pipeline from data download to classifier, saved without outputs.
- `AGENTS.md`: this file.

## Folders
- `docs/`: the picture the README shows (its own `AGENTS.md` lists it).

## Rules
- Real numbers only. The accuracy numbers in the README come from the first full run of this code, not from this saved notebook.
